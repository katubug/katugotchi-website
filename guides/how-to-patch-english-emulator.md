# Guide: How to Apply an English Patch to an Emulated Tamagotchi

You might be wondering how you can play the Tamagotchi P's in English if you don't have the device to apply the patch to. The good news is that while it's complicated, it's totally doable! This guide will walk you through the process. Thanks to [/u/MicroFluff on Reddit for the guide](https://www.reddit.com/r/tamagotchi/s/vgKQ5Yorst)!

**Images will come to this guide in the near future**.

# The Easy Way: Load This Save

1. If you're on PC, visit [Maragotchi's TamaEmu on Github](https://maragotchi.github.io/tamaemu-web/) or [grab it for Windows](https://github.com/maragotchi/tamaemu/releases). You can also use [Mameise's adaptation of TamaEmu for Android](https://github.com/mameise/TamaEmu_Android), but this guide assumes you're on PC.

2. Install the P's firmware into TamaEmu. If you don't know [where to get the firmware](/guides/tamagotchi-downloads/#where-to-get-roms), make sure you check out an **archive** **org**anization who might have them. You'll need to scroll a lot to find them.

3. Download [this file](http://applesims.net/tamagotchi/TamagotchiPsWithEnglishPatches.zip), unzip it, and choose "Import Save" on TamaEmu. If you have any issues with the github or itch.io version of TamaEmu, try importing from the Windows version of the app instead.

4. Scroll down and choose "Add Payload Files" and choose the files for the downloadable content you want installed. - [Where to obtain downloadable content?](/guides/tamagotchi-downloads/)

5. Reload the tama. **Important**: If you want to use your own name and birthdate, **choose "Reset"** instead of "Resume." The English patches will remain installed even if you choose to reset.

6. Export the save as a .sav (there's also a .tamasave option, for this guide you don't need that).

7. In Paramix Studio, go down to Emulator and click "Choose Firmware or ROM." Select the .sav file.

8. Follow the instructions in the [How to Mod a Paradise guide](guides/how-to-mod-tamagotchi-paradise/#how-to-emulate) that I wrote.

# The Manual Way:

The English patches are considered "Destinations," and you can only add 2 at a time due to space constraints. So for the Ps, for example, you'll need to load the first 2, visit those destinations on the device (this is why we do it via TamaEmu instead of Paramix Studio, which would have to re-flash), then delete them and load the second 2.

1. If you're on PC, visit [Maragotchi's TamaEmu on Github](https://maragotchi.github.io/tamaemu-web/) or [grab it for Windows](https://github.com/maragotchi/tamaemu/releases). You can also use [Mameise's adaptation of TamaEmu for Android](https://github.com/mameise/TamaEmu_Android), but this guide assumes you're on PC.

2. Install the P's firmware into TamaEmu. If you don't know [where to get the firmware](/guides/tamagotchi-downloads/#where-to-get-roms), make sure you check out an **archive** **org**anization who might have them. You'll need to scroll a lot to find them.

3. Scroll down and choose "Add Payload Files" - navigate to your English patch files (they will be .jpg) and load the first two.

4. In the emulated game, go to the door icon and press A until you get to the end of the menu, where you'll see your EP-001 destinations.

5. Select the first one and select the top option. The options are "Yes," "No," and "Erase," in that order.

6. Dismiss the warning and press B to install the patch. After pressing B, there will be no indication that the patch is actively installing, so just be patient and wait for TamaEmu to say that the patch is installed.

7. Repeat the process with the second patch.

8. Using the door icon again, go back to your EP files and choose the "Erase" option on them to free up space.

9. Add the second 2 patches, install them and wait for the reboot, then continue your save and repeat the process again for the final 2 patches. Then, delete the final 2 patches as well.

10. Choose "Add Payload Files" again and choose the files for the downloadable content you want installed. You can do this in Paramix Studio as well. - [Where to obtain downloadable content?](/guides/tamagotchi-downloads/)

6. Export the save as a .sav (there's also a .tamasave option, for this guide you don't need that).

7. In Paramix Studio, go down to Emulator and click "Choose Firmware or ROM." Select the .sav file.

8. Follow the instructions in the [How to Mod a Paradise guide](guides/how-to-mod-tamagotchi-paradise/#how-to-emulate) that I wrote.
